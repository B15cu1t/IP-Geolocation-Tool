# IP Geolocation Lookup Tool

A Windows desktop app built in C# for OSINT-style geolocation lookups on any domain or IP address.

## What it does

Enter a domain or IP and get: Country, City, Local time, ISP, Coordinates, and a live Google Maps pin.

## Built with

- C# / Windows Forms
- ip-api.com geolocation API
- .NET Framework

## How to run

Open `Kalkulator.sln` in Visual Studio, build and run.
